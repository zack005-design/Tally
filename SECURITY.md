# Security policy

Tally keeps financial records on the phone, so security reports are taken seriously.

## Supported versions

Only the [latest release](https://github.com/zack005-design/Tally/releases/latest) receives fixes. Update before reporting a problem.

## Report a vulnerability

Please **do not** open a public issue for a security problem. Report it privately instead:

1. Open the repository's [Security tab](https://github.com/zack005-design/Tally/security) and choose **Report a vulnerability**.
2. Describe the problem, the app version and edition (AI or non-AI), your Android version and the steps to reproduce it.
3. Use fictional data. Never attach a real backup, export or receipt.

You should receive a reply within a week. Once a fix is released, the report can be made public with credit to you if you wish.

## In scope

- Access to records without passing the app lock.
- Weaknesses in backup encryption or restore validation.
- Data leaving the device without your action, including through shared reports or receipts.
- Any network access: Tally is built without the internet permission.
