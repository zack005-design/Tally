# Tally 0.2.2

Private development release · Android 8.0+ · Version code 4

The APKs were built from the fixed safety/UI snapshot before the calculator expansion landed on `main`. Use [0.2.3](0.2.3.md) for the combined app with those additional calculator tools.

## Changes

- Reviewed ChatGPT-history import through Tally Companion 0.2.0, with explicit preview and confirmation.
- New full backups require an eight-character password and authenticated encryption. Legacy backups remain importable.
- Restore rejection and rollback tests, populated historical database migration checks, and stricter production-signing configuration.
- App-lock background and inset fixes, large-text checks, press feedback, haptics, and refined screen transitions.
- AI and non-AI editions retain the existing development signing identity and app ID for in-place updates.

The calculator UI test now scrolls the lazy result into view and activates the button through its accessibility semantics, avoiding keyboard-dependent touch geometry. Production calculator code was unchanged by that test correction.

The packaged AI model matches the source model. APK and plugin checksums are attached to the release as **tally-0.2.2-SHA256SUMS.txt**.

## Limits

These are debug-signed testing APKs, not production store builds. Physical-phone and minimum-API testing remain pending. UI tests used Android 16/API36; the available Android 17 emulator had an Espresso incompatibility.

Keep a full encrypted backup before updating or switching editions. Do not uninstall or clear app storage to work around an installation error. App lock does not encrypt the local database. See [installation and data safety](../installation-safety.md).
