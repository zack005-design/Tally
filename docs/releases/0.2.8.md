# Tally 0.2.8 — smoother, with a new lock screen

**Development build** · Android 8.0 or later · Version code 10 · Latest release

Tally now ships as an optimised build, so scrolling, page slides and the back swipe run without the stutters of earlier downloads. The lock screen is redesigned, and saved messages sit at the bottom of the screen. This version installs over 0.2.7 and earlier as an update and is signed with the same certificate, so your records stay on the phone.

## Download

Download `tally-0.2.8.apk` from **Assets** at the bottom of this page.

New to Tally? Follow the [installation guide](../getting-started.md).

## What's new

### Smoother everywhere

- Earlier downloads were debug builds, which Android runs without fully compiling them. 0.2.8 is an optimised build signed with the same development key. In emulator tests, the slowest 1% of frames went from about 2.8 seconds to 0.3 seconds.
- Everything from 0.2.7 still applies: the back swipe follows your finger, taps dim and spring back, and Tally asks for your screen's fastest refresh rate.

### A new lock screen

- The Tally mark and today's date, a large unlock button that gently pulses, **Unlock Tally** at the bottom and a quiet **Use PIN, pattern or password** link.

### Smaller fixes

- Messages such as **Transaction saved** appear as a pill near the bottom, above the tab bar and **Save** buttons.
- The transaction screen shows the account an expense was paid from, instead of **No cash movement**.

## Before you update

- Export an encrypted backup first from the backup screen, and keep the file and its password.
- Install the APK over your current version. Do not uninstall first; uninstalling deletes your records.

## Verification

GitHub Actions publishes this release only after these checks pass:

- Unit tests and Android lint, with the AI models and without them (the rule-based fallback).
- Data-safety and phone-compatibility tests on Android 8, 15, 16 and 17 emulators.
- The APK carries the existing development certificate (SHA-256 `7ddc9c94…b8b865`), the `com.smartexpense` app ID and version code 10, requests no internet permission and is not debuggable.

**Known limits:** a physical phone has not been checked for this build. These are development APKs, not Play Store builds. Checksums are in `tally-0.2.8-SHA256SUMS.txt` under **Assets**.
