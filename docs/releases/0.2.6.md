# Tally 0.2.6 — blue look and a guided first launch

**Development build** · Android 8.0 or later · Version code 8 · Latest release

Tally switches to a crisp blue tint with softer dark greys, and new installs start with a short guided setup. This version installs over 0.2.5 as an update and is signed with the same certificate, so your records stay on the phone.

## Download

Download **one** APK from **Assets** at the bottom of this page. Both editions have the same finance and receipt features and share one app ID, so you can switch later without losing data.

| Edition | File | Choose it if |
| --- | --- | --- |
| **AI** | `tally-0.2.6-ai-debug.apk` | You want a small on-device model to turn short commands such as `coffee 80 cash` into drafts. |
| **Non-AI** | `tally-0.2.6-non-ai-debug.apk` | You prefer rule-based parsing and a smaller download. |

New to Tally? Follow the [installation guide](../getting-started.md).

## What's new

### A new colour

- Blue (#0A66D8) replaces pine green as the app tint on every screen. Money coming in and switches stay green.
- The dark theme uses soft greys (#1C1C1E pages, #2C2C2E cards) instead of pure black. See [appearance](../features/appearance.md).

### A guided first launch

- New installs open with **Welcome to Tally** and **How Tally works**, then set your starting balances.
- An optional step turns on the daily reminder and app lock.
- Restore a backup straight from the welcome screen.
- Summary then opens on a **You're all set** card with a three-step setup list.

### Fits more phones

- Compact phones at their largest display size, and narrow split-screen windows, scale so no screen is laid out narrower than 320 dp. See [phone compatibility](../phone-compatibility.md).
- In landscape, content and the side rail stay clear of the camera cutout or punch-hole.
- The date picker shows the whole week on narrow phones instead of hiding the weekend behind a sideways scroll.

## Before you update

- Export an encrypted backup first from the backup screen, and keep the file and its password.
- Install the APK over your current version. Do not uninstall first; uninstalling deletes your records.
- If you have already set your starting balances, Tally opens straight on Summary as before; the guided setup appears only on a fresh install.

## Verification

GitHub Actions built and published this release only after these checks passed:

- Unit tests and Android lint for both editions.
- Data-safety and phone-compatibility tests on Android 8, 15, 16 and 17 emulators, including a 280 dp date-picker test.
- Both APKs carry the existing development certificate (SHA-256 `7ddc9c94…b8b865`), the `com.smartexpense` app ID and version code 8, and request no internet permission.

**Known limits:** the new first-launch screens and the blue theme have not yet been checked on a physical phone, and the full on-device UI test suite was not run for this build. These are debug-signed development APKs, not Play Store builds. Checksums are in `tally-0.2.6-SHA256SUMS.txt` under **Assets**.
