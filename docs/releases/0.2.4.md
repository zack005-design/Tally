# Tally 0.2.4

Development build · Android 8.0+ · Version code 6 · Latest release

This release brings the receipt, budget and reliability work completed since 0.2.3 to the downloadable APKs. It installs over 0.2.3 as an update; your data stays on the phone.

## Included

- **Complete receipt PDFs.** **Share receipt PDF** now shows the merchant, date and time, category, the account you paid from, every item, taxes or discounts, the total, who paid, each share and what is still owed. When a receipt photo or PDF is attached, its original pages follow in the same file. Private notes and account balances stay out. See [receipts](../features/receipts.md).
- **Receipt review.** Enlarged, zoomable previews, safer receipt replacement, better merchant detection on GST bills, and tilted-photo corrections.
- **Budget alerts.** An optional local notification when this month's spending reaches 80% or 100% of a budget. Off by default; turn it on in **Reminders**. See [spending and planning](../features/spending-and-planning.md).
- **Clearer records.** Repayments name the friend ("Repayment from Maya"), shared refunds need an explicit cash recipient, and Reminders has its own Notifications section in Settings.
- **Fixes.** Wallet opening balances are dated on the setup day so a monthly GPay reset cannot count them twice. The refund editor no longer fails if the original expense changes while open. Home amounts use one consistent format.
- **AI edition.** Includes the integrated command-model extension alongside the original 53,142-parameter model. It still only prepares drafts for you to review. See [on-device AI](../features/on-device-ai.md).

## Verification

- Both editions passed **238 JVM tests**, and Android lint reported no issues for either edition.
- The full instrumented suite ran on an Android 16 (API 36) emulator: **357 of 358 passed**. The remaining case is an intentional assumption skip that only runs in the isolated reference build; it is not an app failure. One layout check that depended on swipe timing was made deterministic afterwards and passed three consecutive runs.
- Real device-PIN unlock, relock after leaving the app, and cancel were verified on the emulator.
- Both APKs were checked for the existing development certificate (SHA-256 `7ddc9c94…b8b865`), the `com.smartexpense` app ID, version code 6 and no Internet permission.

## Installation limits

These are debug-signed development APKs, not production store releases. Physical-phone and minimum-API (Android 8) testing remain pending. Keep a full encrypted backup before updating or switching editions. Checksums are in `tally-0.2.4-SHA256SUMS.txt` on the release page.
