# Tally 0.2.5

Development build · Android 8.0+ · Version code 7

This release brings the iOS-style redesign to the downloadable APKs. It installs over 0.2.4 as an update and is signed with the same development certificate; your data stays on the phone.

## Included

- **New look.** A system-grey background, white grouped lists, solid colour icon squares, contact-style avatars, green switches, the Inter typeface and pine green as the app tint, with a matching black dark theme. See [appearance](../features/appearance.md).
- **New navigation.** A floating bar for **Summary**, **Activity**, **Spending** and **Split**, with a round search button. Add an expense, scan a bill or transfer from the **Summary** card.
- **Rebuilt Summary.** Available to spend, today against your daily limit, this month's budget, what friends owe, recent entries, and a short setup list on first launch.
- **Search.** Search descriptions, notes, categories, accounts, people and tags, this month or all time.
- **Fits every phone.** Phones narrower than 360 dp, or set to a large display size, scale the layout down to fit; your text-size setting still applies. Tablets and foldables keep a phone-width column. See [phone compatibility](../phone-compatibility.md).
- Also includes the unreleased work since 0.2.4: dark theme, yearly summary, tags and adaptive navigation. See the [changelog](../../CHANGELOG.md).

## Verification

This release was built and published by the repository's GitHub Actions workflow, which only publishes after these checks pass:

- JVM unit tests and Android lint for both editions.
- The phone-compatibility instrumented tests on Android emulators at API 26, 35, 36 and 37.
- Both APKs carry the existing development certificate (SHA-256 `7ddc9c94…b8b865`), the `com.smartexpense` app ID, version code 7, and no Internet permission.

The full instrumented UI suite was not run for this build, and the redesign has not yet been checked on a physical phone.

## Installation limits

These are debug-signed development APKs, not production store releases. Keep a full encrypted backup before updating or switching editions. Checksums are in `tally-0.2.5-SHA256SUMS.txt` on the release page.
