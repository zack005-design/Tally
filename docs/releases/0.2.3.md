# Tally 0.2.3

Private development release · Android 8.0+ · Version code 5

This release combines the completed history-import, backup-protection, app-lock and motion updates with the latest offline calculator expansion. It supersedes 0.2.2 without reusing its published build number.

## Included

- Reviewed ChatGPT-history import and Tally Companion 0.2.0.
- Required authenticated encryption for new backups, legacy-backup import, and restore/migration safeguards.
- Improved app-lock layout, press feedback, haptics, and navigation motion.
- Calculator statistics, ratios, percentage changes, tips, reverse tax, and simple/compound-interest arithmetic. See the [calculator guide](../features/calculator.md) for supported inputs and numerical limits.
- AI and non-AI APKs, preserving the development signing identity and app ID used by earlier downloads.

## Verification

Both editions passed **173 JVM tests**. Debug assembly and Android lint passed for each edition, with zero lint errors; existing warnings remain. The exact AI APK passed two calculator UI checks on Android 16/API36, including typed decimal arithmetic, editing a prior result, and guided equal splitting at narrow width and large text.

The preceding [0.2.2 verification](0.2.2.md) records 18 passing targeted device checks for the unchanged backup, migration, lock, draft, model and distribution behaviour. Those results are a baseline, not a claim that all 18 cases were rerun for this version.

Both APKs are checked for signature validity, the existing development certificate, `com.smartexpense`, version code 5, no Internet permission, disabled automatic Android backup, and correct model presence/absence. Release checksums cover both APKs and the Companion ZIP.

## Installation limits

These are debug-signed development APKs, not production store releases. Physical-phone and minimum-API testing remain pending. Downloads remain private and require repository access. Keep a full encrypted backup before updating; do not uninstall or clear storage to switch editions.
