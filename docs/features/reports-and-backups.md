# Reports and backups

Export a readable report to review your records, or create a full backup for restoration. These files serve different purposes.

<p align="center"><a href="../screenshots/all-screens/export.png"><img src="../screenshots/all-screens/export.png" width="300" alt="Tally report export options and preview"></a></p>

## Export a report

1. Open the export screen and select the month.
2. Choose **Statement** or **Transactions**.
3. Select **CSV** for spreadsheet analysis or **PDF** for a readable report.
4. Check the preview and filename, then export to a location you choose.

Reports are for reading, sharing, and analysis. A CSV or PDF cannot restore your Tally database.

## Create a restorable backup

Use the backup screen to export a full backup. Set a password when creating a password-protected backup, and keep both the file and password somewhere you can access later. Restore through the backup flow using a compatible backup file.

Automatic Android cloud backup is disabled. You decide where to store your exported backup.

| File | Best for | Restores app data? |
| --- | --- | --- |
| CSV report | Reviewing transactions in a spreadsheet or with a companion plugin | No |
| PDF report | Reading or sharing a formatted report | No |
| Full backup | Restoring your records through Tally's backup flow | Yes |

## Review an export with Tally Companion

Export a **Transactions CSV** for the month you want to review. In Codex, use your Tally Companion or Tally Toolkit plugin and explicitly attach the exported file.

The plugins run separately in Codex. Tally does not upload records automatically; only share an export when you want it reviewed.
