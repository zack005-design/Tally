# Downloads

The app and plugins are available from public GitHub Releases. Choose a download below; a GitHub account is not required.

## Android AI edition

[Open Android downloads](https://github.com/zack005-design/Tally/releases/tag/v0.2.3-20261024)

[Download AI APK](https://github.com/zack005-design/Tally/releases/download/v0.2.3-20261024/tally-0.2.3-ai-debug.apk), or expand **Assets** and select **tally-0.2.3-ai-debug.apk**. This edition includes the custom on-device expense-command model, calculator, and receipt scanner.

## Android non-AI edition

[Open Android downloads](https://github.com/zack005-design/Tally/releases/tag/v0.2.3-20261024)

[Download non-AI APK](https://github.com/zack005-design/Tally/releases/download/v0.2.3-20261024/tally-0.2.3-non-ai-debug.apk), or expand **Assets** and select **tally-0.2.3-non-ai-debug.apk**. This edition uses rule-based expense parsing. It still includes the calculator and existing receipt OCR.

Both APKs require Android 8.0 or later and are development builds. They share an app identity and replace one another. Create a full backup before updating or switching; do not uninstall just to switch editions.

## Tally Companion

[Open plugin downloads](https://github.com/zack005-design/Tally/releases/tag/v0.2.3-20261024)

Under **Assets**, select **tally-companion-0.2.0.zip**. This Codex plugin reviews spending exports and prepares chat-history files for reviewed import into Tally. It is not an Android installer.

## Tally Toolkit

[Open plugin downloads](https://github.com/zack005-design/Tally/releases/tag/v0.1.0-ios-polish-20261021)

Under **Assets**, select **tally-toolkit-0.1.0.zip**. This is the Codex plugin for working on Tally and reviewing user-provided exports.

## If the download does not start

1. Choose **Open in browser** if the page is inside a chat or another app.
2. Open the release linked above in that browser.
3. Open the release above, expand **Assets**, and choose the exact filename.
4. Check the browser's Downloads list. If a saved link returns 404, use the release above and report the filename and browser if it still fails.

**Source code (zip)** and **Source code (tar.gz)** contain project source, not installable APKs. For app installation, use an **.apk** file.
