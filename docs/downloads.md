# Downloads

The app and plugins are attached to GitHub Releases. This repository is private: open the release in a regular browser and sign in with an account that has repository access. A private file may return **404** when its download request is not authenticated, even if you can see the release in another browser.

## Android AI edition

[Open Android downloads](https://github.com/zack005-design/Tally/releases/tag/v0.2.2-20261024)

Expand **Assets** and select **tally-0.2.2-ai-debug.apk**. This edition includes the custom on-device expense-command model, calculator, and receipt scanner.

## Android non-AI edition

[Open Android downloads](https://github.com/zack005-design/Tally/releases/tag/v0.2.2-20261024)

Expand **Assets** and select **tally-0.2.2-non-ai-debug.apk**. This edition uses rule-based expense parsing. It still includes the calculator and existing receipt OCR.

Both APKs require Android 8.0 or later and are development builds. They share an app identity and replace one another. Create a full backup before updating or switching; do not uninstall just to switch editions.

## Tally Companion

[Open plugin downloads](https://github.com/zack005-design/Tally/releases/tag/v0.2.2-20261024)

Under **Assets**, select **tally-companion-0.2.0.zip**. This Codex plugin reviews spending exports and prepares chat-history files for reviewed import into Tally. It is not an Android installer.

## Tally Toolkit

[Open plugin downloads](https://github.com/zack005-design/Tally/releases/tag/v0.1.0-ios-polish-20261021)

Under **Assets**, select **tally-toolkit-0.1.0.zip**. This is the Codex plugin for working on Tally and reviewing user-provided exports.

## If the download does not start

1. Choose **Open in browser** if the page is inside a chat or another app.
2. Sign in to GitHub in that same browser using an account with access to Tally.
3. Open the release above, expand **Assets**, and choose the exact filename.
4. Check the browser's Downloads list. If you still get a 404 while signed in, report the filename and browser so the failing request can be checked.

**Source code (zip)** and **Source code (tar.gz)** contain project source, not installable APKs. For app installation, use an **.apk** file.
